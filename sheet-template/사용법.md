# 원두 목록 시트 사용법

홈페이지의 원두 목록은 구글 시트에서 관리합니다. 시트에서 원두를 고치면 **코드를 건드리지 않아도** 홈페이지에 반영됩니다.

- 양식 파일: `원두목록_양식.csv` (예시 원두 8종이 들어 있음)

---

## 1. 처음 한 번만: 시트 만들기

1. [구글 시트](https://sheets.google.com)에서 **빈 스프레드시트**를 만듭니다.
2. 메뉴에서 **파일 → 가져오기 → 업로드**를 누르고 `원두목록_양식.csv`를 올립니다.
3. 가져오기 위치는 **현재 시트 바꾸기**, 구분자 유형은 **자동으로 감지**를 고르고 **데이터 가져오기**를 누릅니다.
4. 아래쪽 시트 탭 이름을 `원두`로 바꿉니다.
5. (권장) 아래 **3. 입력 실수 막기**를 설정합니다.

## 2. 처음 한 번만: 홈페이지와 연결하기

1. 메뉴에서 **파일 → 공유 → 웹에 게시**를 누릅니다.
2. **링크** 탭에서 `전체 문서` 대신 **`원두`** 시트를 고르고, 형식은 **쉼표로 구분된 값(.csv)** 을 고릅니다.
3. **게시**를 누르고 나온 주소를 복사합니다.
   - 주소는 `https://docs.google.com/spreadsheets/d/e/.../pub?gid=...&single=true&output=csv` 모양입니다.
4. 복사한 주소를 `hearth-roastery/assets/js/main.js`의 `beansSheetCsv: ""` 따옴표 안에 붙여 넣습니다. 개발 담당자에게 주소만 전달해도 됩니다.

> ⚠️ **웹에 게시한 시트는 주소를 아는 누구나 볼 수 있습니다.** 원가, 거래처, 메모처럼 공개하면 안 되는 내용은 이 시트에 적지 말고 **다른 시트 탭**에 적으세요. 2번 단계에서 `원두` 시트만 게시하면 다른 탭은 공개되지 않습니다.

## 3. 입력 실수 막기 (권장)

열을 선택한 뒤 **데이터 → 데이터 확인 → 규칙 추가 → 드롭다운**으로 아래 값만 고를 수 있게 하면 오타가 줄어듭니다.

| 열 | 드롭다운 값 |
|---|---|
| 유형 | `블렌드`, `싱글` |
| 로스팅 | `라이트`, `라이트미디엄`, `미디엄`, `미디엄다크`, `다크` |
| 대표, 노출여부 | `Y`, `N` |

## 4. 열 설명

**1행(제목 줄)의 글자는 바꾸지 마세요.** 홈페이지가 제목으로 열을 찾습니다. 열 순서는 바꿔도 됩니다.

| 열 | 필수 | 설명 | 예시 |
|---|---|---|---|
| 아이디 | ✅ | 주소에 쓰이는 영문 이름. 소문자와 `-`만 사용합니다. **한 번 정하면 바꾸지 마세요** (바꾸면 공유된 링크가 깨집니다) | `kenya-nyeri` |
| 이름 | ✅ | 홈페이지에 보이는 원두 이름 | `케냐 니에리` |
| 영문명 | | 원두 봉투 그림에 들어가는 영문. 짧을수록 보기 좋습니다 | `NYERI` |
| 유형 | ✅ | `블렌드` 또는 `싱글`. 원두 목록 필터에 쓰입니다 | `싱글` |
| 산지 | | 나라와 지역 | `케냐 니에리` |
| 가공 | | 가공 방식 | `워시드` |
| 고도 | | 재배 고도. 비우면 상세 화면에서 이 줄이 숨겨집니다 | `1,600~2,000m` |
| 산지이야기 | | 원두 상세 화면에 나오는 2~3문장 소개. 실제로 들여온 농장·생두 정보가 있으면 그걸 적는 게 가장 좋습니다 | `케냐 산 남서쪽 비탈의…` |
| 로스팅 | | 로스팅 정도 (3번의 드롭다운 값 권장) | `라이트미디엄` |
| 컵노트 | | 맛 표현. **쉼표로 구분**하고 3개 정도가 적당합니다 | `블랙커런트, 자몽, 흑설탕` |
| 산미 | | 1~5 숫자. 막대 그래프로 표시됩니다 | `5` |
| 바디 | | 1~5 숫자 | `3` |
| 가격 | ✅ | 200g 가격. 숫자만 적습니다 (`21,000원`도 인식함) | `21000` |
| 추천추출 | | 어울리는 추출 방법 | `핸드드립` |
| 색상 | | 원두 봉투 그림 색. `#`과 6자리 색상 코드 | `#8c2f39` |
| 스토어링크 | | 이 원두의 **스마트스토어 상품 주소**. `https://`로 시작해야 합니다. 비우면 스토어 메인으로 연결됩니다 | `https://smartstore.naver.com/...` |
| 사진URL | | 원두 사진 주소 (`https://`). 넣으면 봉투 그림 대신 사진이 보입니다. 세로가 조금 긴 사진(가로:세로 = 200:260)이 가장 잘 맞습니다 | |
| 대표 | | `Y`면 홈 화면 "이번 시즌의 원두"에 나옵니다. **2개만** `Y`로 하세요 | `Y` |
| 노출여부 | | `N`이면 홈페이지에서 숨깁니다. 시즌이 끝난 원두는 지우지 말고 `N`으로 바꾸세요 | `Y` |

## 5. 자주 하는 작업

- **새 원두 추가:** 맨 아래에 한 줄을 추가합니다. 아이디는 다른 원두와 겹치면 안 됩니다.
- **시즌 종료:** 노출여부를 `N`으로 바꿉니다. 다음 시즌에 `Y`로 바꾸면 다시 나옵니다.
- **순서 바꾸기:** 원두 목록의 "추천순"은 **시트의 줄 순서**를 따릅니다. 먼저 보여 주고 싶은 원두를 위로 옮기세요.
- **가격 변경:** 홈페이지 가격만 바뀝니다. **스마트스토어 가격도 꼭 같이 바꾸세요.**

## 6. 알아 두면 좋은 점

- 시트를 고친 뒤 홈페이지에 반영되기까지 **최대 5분 정도** 걸릴 수 있습니다 (구글 쪽 갱신 주기).
- 시트를 읽지 못하면 홈페이지는 미리 넣어 둔 기본 원두 목록(`beans-data.js`)을 대신 보여 줍니다. 시트를 고쳤는데 반영되지 않으면 1행 제목이 바뀌지 않았는지 먼저 확인하세요.
- 엑셀로 이 CSV를 열어도 한글이 깨지지 않습니다. 다만 홈페이지 연결은 **구글 시트**로만 됩니다.
