# 납품 문의 → 구글 시트·메일 연동 배포 방법

홈페이지의 **납품 문의 폼**에 입력된 내용을 구글 시트에 저장하고, 새 문의가 오면 메일로 알려 주는 설정입니다. 처음 한 번만 하면 되고, 15분 정도 걸립니다.

- 코드: `Code.gs`, `appsscript.json` (이 폴더)
- 필요한 것: 문의를 받을 **구글 계정**. 이 계정의 Gmail로 알림이 갑니다.

---

## 1. 시트 만들기

1. [구글 시트](https://sheets.google.com)에서 **빈 스프레드시트**를 만들고, 이름을 `Hearth Roastery 문의`로 바꿉니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 누릅니다. 새 탭에 편집기가 열립니다.

## 2. 코드 붙여 넣기

1. 편집기의 `Code.gs`에 있는 기본 코드(`function myFunction() {}`)를 **모두 지우고**, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣습니다.
2. (권장) 왼쪽 **⚙ 프로젝트 설정**에서 **"편집기에 'appsscript.json' 매니페스트 파일 표시"**를 체크합니다. 편집기로 돌아가 `appsscript.json`을 열고, 이 폴더의 `appsscript.json` 내용으로 바꿉니다.
   - 시간대를 서울로 맞추고, 필요한 권한만 요청하게 해 줍니다.
3. 💾 **저장**(Ctrl+S)을 누릅니다.

## 3. 처음 한 번 실행 (권한 허용)

1. 편집기 위쪽 함수 선택 칸에서 **`setup`**을 고르고 **▶ 실행**을 누릅니다.
2. **권한 검토 → 계정 선택**을 합니다.
3. **"Google에서 확인하지 않은 앱"** 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음)**을 누릅니다.
   - 사장님이 직접 만든 스크립트라서 나오는 안내입니다.
4. **허용**을 누릅니다. 요청하는 권한은 아래 네 가지입니다.
   - 이 스프레드시트 보기·편집
   - 내 이름으로 메일 보내기 (알림용)
   - 트리거 관리 (매일 자동 삭제용)
   - 내 이메일 주소 확인 (알림 받을 주소)
5. 아래 **실행 로그**에 `준비 완료: …`가 나오면 성공입니다. 시트에 **`문의` 탭**이 생겼는지 확인하세요.

## 4. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. ⚙ **유형 선택 → 웹 앱**을 고릅니다.
3. 아래처럼 설정합니다.
   - 설명: `홈페이지 문의 접수`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고, 나온 **웹 앱 URL**을 복사합니다. 주소는 `https://script.google.com/macros/s/…/exec` 모양입니다.
5. 복사한 주소를 브라우저 새 탭에서 열어 봅니다. `{"ok":true,"service":"hearth-roastery-inquiry"}`가 보이면 정상입니다.

> "모든 사용자"로 해야 홈페이지 방문자가 문의를 보낼 수 있습니다. 보낼 수만 있고, 시트 내용은 볼 수 없습니다.

## 5. 홈페이지에 연결

웹 앱 URL을 Claude에게 알려 주세요. `hearth-roastery/assets/js/main.js`의 `formEndpoint`에 넣고 푸시하면, 1분 안에 공개 사이트에 반영됩니다.

직접 할 때는 아래처럼 넣으면 됩니다.

```js
formEndpoint: "https://script.google.com/macros/s/…/exec",
```

## 6. 실제로 시험하기

1. 공개 사이트의 **납품 문의** 페이지에서 시험 문의를 하나 보냅니다. 폼을 연 뒤 **3초 이상** 지나서 보내야 합니다 (스팸 방지 장치).
2. 시트의 `문의` 탭에 한 줄이 추가됐는지 확인합니다.
3. Gmail에 **`[납품 문의] 상호 · 이름`** 메일이 왔는지 확인합니다.
4. 시험한 줄은 지워도 됩니다.

---

## 운영하면서 알아 둘 점

| 상황 | 방법 |
|---|---|
| 문의를 처리했을 때 | `처리 상태` 칸을 `신규` → `연락 완료` 등으로 바꿔 쓰세요 |
| 알림을 다른 메일로 받고 싶을 때 | Apps Script **⚙ 프로젝트 설정 → 스크립트 속성**에 `NOTIFY_EMAIL` = 받을 주소 추가 |
| 코드를 고쳤을 때 | **배포 → 배포 관리 → ✏ 편집 → 버전: 새 버전 → 배포**. 주소가 바뀌지 않아 홈페이지는 그대로 둬도 됩니다 |
| 1년 지난 문의 | 매일 새벽 4시에 자동으로 지워집니다 (개인정보 동의 문구와 일치) |
| 알림 메일이 안 올 때 | 일반 Gmail은 하루 약 100통까지 보낼 수 있습니다. 시트에는 그대로 저장됩니다 |

**스팸 방지 장치** (방문자에게는 보이지 않습니다)
- 사람에게는 안 보이는 칸이 채워진 전송은 저장하지 않습니다.
- 폼을 연 지 3초 안에 보낸 전송은 저장하지 않습니다.
- 같은 연락처로 1분 안에 다시 보내면 막습니다.
- 전체 접수는 1분에 20건까지 받습니다.

**주의:** 이 시트에는 문의자의 연락처가 들어 있습니다. 시트의 공유 설정을 "링크가 있는 모든 사용자"로 바꾸지 마세요.
